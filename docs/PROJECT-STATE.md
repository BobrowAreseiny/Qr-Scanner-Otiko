## Принятые решения

### Интерфейс

- PIN и роли отсутствуют: настройки доступны любому пользователю ТСД.
- Язык интерфейса — русский.
- Заголовок «Сканер QR», крупный заголовок «УЧЁТ КОРОБОВ».
- Строгое оформление по мотивам Scan2ERP.
- Палитра: `#1E3A8A`, `#F4F5F7`, белый, тёмно-серый текст.
- Клавиши: `1` — основное действие, `2` — QR, `0` — назад.
- Справка соответствует текущему интерфейсу.
- Звук — штатный сканер.

### Короба и марки

- Ёмкость короба: 12, 10, 5 или 3 марки.
- Одна марка не может находиться в двух коробах.
- QR-код короба содержит числовой ID.
- Поиск по марке: марка → короб → удаление марки.

### Заказы

- Смешанный заказ разрешён: короба и отдельные марки.
- История заказов сохраняется.
- При удалении заказа короба остаются на складе, статус «Отгружен» снимается.
- В заказе доступны действия «Отправлено» и «Вернуть на склад».
- Без авторизации Datamark марка не добавляется: выводится сообщение «Требуется авторизация» и кнопка перехода в настройки.

### Данные и безопасность

- SQLCipher; ключ хранится в `SecureStorage`; слой шифрования заменяемый.
- Код восстановления БД и автоматические зашифрованные копии: ежедневно (7), еженедельно (4), ежемесячно (3), плюс ручная копия.
- Код восстановления отображается в настройках, доступны копирование и отправка файлом.
- Восстановление из копии выполняется через выбор файла.
- Логи записываются в файл без паролей и ключей; предусмотрены просмотр и отправка.
- Данные удаляются только вручную, автоматическая очистка отсутствует.
- Настройки Электронного знака (Datamark) без PIN — согласовано.

### Платформа и экспорт

- Android 7+, ARMv7 и ARM64.
- 1С: основной способ — HTTP API; файл `.txt` сохраняется как резервный. Контракт описан в `docs/1C-API.md`.
- CI: GitHub Actions — сборка и тесты.
- Способ распространения APK определяется позже.

## Открытые вопросы

- Пароль API Электронного знака: предоставленный пароль не прошёл `/auth` (нужен спецсимвол); проверка с ведущими и завершающими пробелами дала ту же ошибку. Ожидается актуальный пароль API либо подтверждение доступа в поддержке Datamark.
- Реальный API Электронного знака (Datamark) не проверен.
- Официальные приложения и установка описаны в `docs/DATAMARK.md`.
- Пример `.txt` для 1С: ожидается как резервный формат.
- Адрес, авторизация и формат API 1С: ожидаются; предложен контракт в `docs/1C-API.md`.
- Тестовый контур 1С для проверки обмена: не предоставлен.
- Keystore старого QRScanner неизвестен; возможность обновления поверх старой версии не подтверждена.
- Системное окно «Поделиться» на эмуляторе не открылось: требуется проверка на ТСД.
- ТСД отключён: проверка на устройстве отложена, последние ветки проверены на эмуляторе.
