## Принятые решения

### Интерфейс

- Без PIN и ролей: настройки доступен любому пользователю ТСД.
- Только русский язык.
- Заголовок «Сканер QR», крупный заголовок «УЧЁТ КОРОБОВ».
- Строгий визуал по мотивам Scan2ERP, палитра `#1E3A8A`, `#F4F5F7`, белый, тёмно-серый текст.
- Клавиши: `1` — основное, `2` — QR, `0` — назад.
- Справка — новая, под текущий интерфейс.
- Звук — штатный сканер.

### Короба и марки

- Ёмкость короба: 12 / 10 / 5 / 3.
- Одна марка не может быть в двух коробах.
- QR короба содержит числовой ID.
- Поиск по марке нужен: сканировать марку → найти короб → при необходимости удалить марку.

### Заказы

- Смешанный заказ разрешён: короба и отдельные марки.
- История заказов нужна.
- При удалении заказа короба остаются на складе, статус «Отгружен» снимается.
- Два действия: «Отправлено» и «Вернуть на склад».
- Без авторизации Datamark марку не добавлять: сообщение «Требуется авторизация» и кнопка перехода в настройки.

### Данные и безопасность

- SQLCipher, ключ в SecureStorage; слой шифрования заменяемый.
- Код восстановления БД + автоматические зашифрованные копии: ежедневно (7), еженедельно (4), ежемесячно (3), плюс ручная кнопка.
- Код восстановления показывать в настройках, копировать/отправлять файлом.
- Восстановление из копии через выбор файла.
- Логи — в файл, без паролей и ключей; предусмотреть просмотр/отправку.
- Данные удаляются только вручную, автоочистки нет.
- Настройки Datamark без PIN — согласовано.

### Платформа и экспорт

- Android 7+, ARMv7/ARM64.
- 1С: оба варианта — файл сейчас, API-экспорт через отдельный интерфейс позже. Формат и протокол уточняются.
- CI: GitHub Actions — сборка и тесты.
- Распространение APK — позже.
