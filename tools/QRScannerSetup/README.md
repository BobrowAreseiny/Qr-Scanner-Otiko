# QRScannerSetup

Разовая настройка общей папки Windows для QRScanner.

## Запуск

1. Скопируйте `QRScannerSetup.exe` (один файл) на Windows 7/11.
2. Запустите `QRScannerSetup.exe` от имени администратора.
3. Подтвердите UAC.

Программа создаст:

- `C:\QRScanner\Заказы`
- `C:\QRScanner\QR-коды`
- `C:\QRScanner\Обновления`
- локального служебного пользователя `qrscanner`;
- общую папку `QRScanner`;
- правила брандмауэра для TCP 445, UDP 137 (NetBIOS) и UDP 5355 (LLMNR);
- при необходимости включает NetBIOS over TCP/IP (на Windows 7 нужна перезагрузка).

После завершения откроется окно с QR-кодом настроек и файл:

```text
C:\QRScanner-access.txt
```

В файле `Server` — имя компьютера, а также папка, пользователь и пароль.

## Несколько пользователей на компьютере

Служебная учётная запись не должна совпадать с учётной записью человека.
Установщик проверяет имя `qrscanner`:

- если такого пользователя нет — создаёт его;
- если `qrscanner` уже создан этим установщиком (в описании есть `QRScanner`) — обновляет пароль;
- если имя `qrscanner` занято человеком — выбирает `qrscanner2`, `qrscanner3` и так далее.

Выбранное имя записывается в `C:\QRScanner-access.txt`, в общую папку, права NTFS и QR-код.
Повторный запуск находит созданную ранее служебную учётку по описанию и использует её.

Принудительно задать имя можно параметром:

```text
QRScannerSetup.exe --user qrscanner5
```

## Настройка ТСД по QR

1. На компьютере запустите `QRScannerSetup.exe` (или `QRScannerSetup.exe --qr-only`, если QR-окно закрыли).
2. На ТСД: `Настройки → Компьютер → Сканировать QR настроек`.
3. Наведите сканер на QR-код с экрана компьютера.
4. Приложение само запишет имя компьютера, папку, пользователя и пароль и проверит подключение.

В поле «Сервер» используется имя компьютера, например `BEAVER-JR`. При смене IP имя остаётся, поэтому перенастройка не нужна.

## Определение Windows

Программа сама определяет версию:

- Windows 7 / Server 2008 R2 — при необходимости включает SMB2 в реестре;
- Windows 8 / 8.1 / 10 / 11 — использует штатный SMB2/3, реестр не меняет;
- Windows XP — сообщает, что версия не поддерживается;
- Windows Vista / Server 2008 — включает SMB2.

## Импорт настроек на ТСД (запасной вариант)

1. Скопируйте `C:\QRScanner-access.txt` на ТСД:
   - в `Android/data/by.otiko.qrscanner/files/` по USB; или
   - в `Download`.
2. В приложении откройте `Настройки → Компьютер (SMB)`.
3. Нажмите `Импорт из файла`.
4. Нажмите `Проверить`.

Приложение сначала ищет файл в папке приложения, затем в `Download`.

## Обновление приложения через SMB

1. Поднимите `ApplicationDisplayVersion` и `ApplicationVersion` в `QRScanner.App.csproj`.
2. Соберите подписанный Release APK тем же keystore.
3. Положите APK в `C:\QRScanner\Обновления`.
4. Создайте `C:\QRScanner\Обновления\version.json`:

```json
{
  "version": "1.4.0",
  "versionCode": 15,
  "file": "QRScanner-1.4.0.apk",
  "sha256": "необязательно, контрольная сумма APK",
  "notes": "Что изменилось"
}
```

5. На ТСД: `Настройки → Обновление приложения → Проверить обновление`.
6. Разрешите установку из этого источника и нажмите `Обновить`.

Данные приложения сохраняются. `versionCode` должен быть больше установленного.

## Если не удаётся создать пользователя

По умолчанию установщик создаёт локального пользователя через API Windows
(`System.DirectoryServices.AccountManagement`), а не через `net user`.

Если появилась ошибка создания пользователя:

1. Закройте установщик.
2. Создайте пользователя вручную от администратора:

```text
net user qrscanner "QrScanner2026" /add /expires:never /passwordchg:no
```

Если команда тоже зависает, создайте пользователя через
`Параметры → Учётные записи → Другие пользователи → Добавить учётную запись`
(имя `qrscanner`, пароль `QrScanner2026`).

3. Создайте `C:\QRScanner-access.txt` с одной строкой:

```text
Password=QrScanner2026
```

4. Запустите установщик с пропуском пользователя:

```text
QRScannerSetup.exe --skip-user
```

Установщик создаст папки, общую папку, права и QR-код, используя пароль из файла.
Затем отсканируйте QR на ТСД или импортируйте `C:\QRScanner-access.txt`.

## Предупреждение Windows о вирусе

`QRScannerSetup.exe` не подписан сертификатом подписи кода, поэтому Windows
SmartScreen и антивирусы могут показать «Неизвестный издатель» или ложное
срабатывание. Проверьте SHA-256 по `SHA256.txt` из комплекта. Если хеш
совпадает, разрешите запуск: «Подробнее» → «Выполнить в любом случае»
(или «Журнал защиты» → «Действия» → «Разрешить на устройстве»).

Для поставки на чужие компьютеры без таких предупреждений нужен
сертификат подписи кода и подпись `signtool.exe`.

## Важно

- Никакого фонового приложения не устанавливается: используется встроенный SMB Windows.
- Компьютер должен быть включён и не уходить в сон.
- Сканер и компьютер должны быть в одной сети.
- На Windows 7 после включения NetBIOS перезагрузите компьютер.
- Пароль из `C:\QRScanner-access.txt` и QR-код настроек не публикуйте.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Требуется .NET Framework 4.0 (включая `System.DirectoryServices.AccountManagement`).
`QRCoder.dll` (net40) нужен только при сборке: он встраивается в `QRScannerSetup.exe`,
поэтому готовому установщику отдельная DLL не нужна.
